◆ CY_SCB_EZI2C_EZ_DATA_SIZE

#define CY_SCB_EZI2C_EZ_DATA_SIZE   (CY_SCB_FIFO_SIZE * 2UL)

The number of EZ_DATA registers available in hardware EZ mode, derived from the SCB FIFO size (the EZ_DATA memory is two bytes per FIFO entry) and capped at CY_SCB_EZI2C_EZ_MAX_DATA_SIZE.

Each register holds one byte of data (bits [7:0] are used).
